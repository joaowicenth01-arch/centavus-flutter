# CENTAVUS-V2.0

## Abra o aplicativo

[Abrir o Centavus em formato de celular](https://joaowicenth01-arch.github.io/centavus-flutter/mobile-preview.html)

O aplicativo roda no navegador. O cadastro e os dados financeiros ficam salvos localmente no navegador utilizado e não são sincronizados entre dispositivos.

O código Flutter está na pasta [flutter_app](flutter_app/), e o roteiro da apresentação está em [ROTEIRO-APRESENTACAO.md](ROTEIRO-APRESENTACAO.md).
